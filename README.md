# 🎃 Umbra

A deep-dark **BetterDiscord theme** with pumpkin-orange and neon-purple glow, toxic-green highlights, and subtle spooky details. *Umbra* means the darkest part of a shadow, and that's exactly the mood: a haunted, premium gaming-client look that works all year.

## What you get

- Clean, deep-dark look across all of Discord
- Warm orange glow with purple accents
- Green pops for rewards and unreads
- Glowing server icons and highlighted channels
- A faint moon-and-graveyard scene behind your chats
- A cobweb in the corner and a tiny bat up top
- Styled Quests page with glowing cards
- Matching orange-to-purple scrollbar
- Calms down if you've got Reduce Motion on

## 📥 Installation

1. Install [BetterDiscord](https://betterdiscord.app) if you haven't already.

2. Download **`Umbra.theme.css`** from this repo (or the latest release).

3. In Discord: **Settings → Themes → Open Themes Folder**.

4. Move `Umbra.theme.css` into that folder.

5. Turn on **Umbra** in the Themes list.

It applies instantly. No restart needed.

## 🎨 Customizing the colors

All colors live at the top of the file in the **PALETTE** section. Change these values and the whole theme updates:

```css
:root {
  --hn-pumpkin: #ff7518;  /* primary accent */
  --hn-purple:  #8b3dff;  /* secondary accent */
  --hn-toxic:   #9dff57;  /* highlights */
}
```
